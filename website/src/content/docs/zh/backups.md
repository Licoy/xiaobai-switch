每次写入 Claude Code、Codex、Pi 或 Prime 之前，应用会把当前目标文件备份到 `~/.xiaobai-switch/backups/`。各目标有独立目录；Pi 与 Prime 都会一起备份 `models.json`、`auth.json` 与 `settings.json`。

## 在应用中心

每个目标表单下方可以看到备份记录：预览摘要、查看源文件、还原、删除。

还原会 **直接覆盖当前配置文件**，当前文件会被替换且无法撤销（还原前不会再套一层备份提示以外的保险，请先看摘要）。删除后无法恢复。

## 保留份数

**设置 → 备份**：每个应用最多保留份数，默认 30。超出后自动删除该应用最旧的备份。可从设置打开备份目录。

## 应用数据备份与 WebDAV

原生 1.x 的应用 ZIP 备份保存在 `~/.xiaobai-switch/app-backups/`，包含一致性的数据库快照、`master.key` 与校验清单，备份文件含解密应用密钥所需材料，请妥善保管。

恢复先创建恢复前快照，再写入待恢复队列，重启后在打开数据库前替换；应用数据恢复不会自动修改四目标 CLI 配置，需要时在应用中心重新确认并应用。

WebDAV 可测试连接、上传、下载、删除备份并定时同步，自动保留清理仅处理当前设备的备份；密码加密保存在应用数据库，上传成功后的清理警告会单独展示。
